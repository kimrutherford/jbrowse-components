This major version bump marks the inclusion of two "breaking" changes

These breakages should be non-intrusive to most users but to be a good "semantic
versioning" citizen, we mark this as a major version bump

The major changes include

1. Changing the "filehandle" type used in data adapters. We now use
   generic-filehandle2 which is simpler and does not require a node.js polyfill
   on the web
2. Upgrading React 18 -> React 19 in our main webapp. This drops support for
   React 17

Aside from this there are a number of small changes and improvements, see below
